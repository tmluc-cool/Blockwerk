# Template projects

**File → New Project from Template …** opens one of five small projects. Each is one scene, made from
library models and simple shapes, with one or two block scripts that show how the game works.
Open the scripts (double-click the script component on an object) and change them.

| Template       | Genre                      | What it shows                                                                                                         |
| -------------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Adventure**  | Third-person adventure     | Character with third-person camera, coins that go into the inventory (Pickup), a flag that ends the walk (Zone).      |
| **Arena**      | First-person shooter       | First-person control, a bullet prefab (Projectile) fired by the Attack button, skeletons that chase and attack (NPC). |
| **Platformer** | 3D jump-and-run            | Platforms over the void, double jump, gems, and a script that puts you back on the start point after a fall.          |
| **Co-op**      | Collecting game, 2 players | Two players in split screen with their own cameras, one shared counter, a "wait until" that ends the game.            |
| **Racing**     | Small racing game          | Vehicle controller, a finish line and a halfway line that count laps with variables, a log message after three laps.  |

All of them start with a hint in the console (Window → Console) that says how to play. Controls are
the ones of the editor's Play mode: WASD and mouse; player 2 uses the arrow keys or a gamepad.

The templates are generated by `pnpm templates` (`scripts/make-templates.mjs`) into `templates/`, so
they stay readable and identical on every machine. A test (`apps/editor/test/templates.test.ts`)
opens every template, runs the scene check, plays it and tries its one mechanic; another one
(`e2e/editor/templates.spec.ts`) does the same in the editor.
