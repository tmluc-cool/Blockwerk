# Final acceptance (SPEC phase 11)

The final game is **`examples/endspiel`** ("Das Dorf Birkenau"), generated by
`scripts/make-endspiel.mjs`, tested by `apps/editor/test/endspiel.test.ts` (13 tests on the real
project) and `e2e/editor/phase11.spec.ts` (the game in the editor).

Try it: **File → Open Example Project → Endspiel**, press Play. Keys: WASD walk, Shift run,
Space jump (twice for the double jump), Q roll, E talk, F strike, H drink a potion, Esc pause,
**Enter: player 2 joins** (arrow keys; split screen).

## Quality targets (SPEC 12)

| Target                                           | Result                                                                                                                                                                                                |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ≥ 60 FPS in the landscape                        | **Open**, needs real hardware (see above).                                                                                                                                                            |
| Draw calls in the landscape on "Hoch" < 500      | Met: 107–162 in the final game, about 120 in `04-landschaft` (`phase11.spec.ts` and `phase4.spec.ts` fail above 500).                                                                                 |
| Click on Play until the game runs < 1 s          | **Not met here:** 1.1 s for the final game's menu scene in the software renderer (30–160 ms for the small examples). Likely dominated by the software renderer, to be re-measured on a graphics card. |
| Open a project with 80 block scripts < 3 s       | Met: `example07.test.ts` (86 scripts, load and compile under 3 s).                                                                                                                                    |
| Save an unchanged project: 0 Git changes         | Met: every example and template has this test, the final game too.                                                                                                                                    |
| Error messages in German and English with a jump | Met: `i18n.test.ts` (every key in both languages), console rows link to the block or object (`phase8.spec.ts`).                                                                                       |
| Editor crash through an error in the game: never | No crash seen in any test; script errors are caught per script and shown in the Console (phase 8).                                                                                                    |
