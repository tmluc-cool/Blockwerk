# Test sheet: "Does Blockwerk feel like Unity?"

For a tester who has used Unity. Give them Blockwerk and this page, but **no explanation**. Watch,
do not help, and note where they hesitate. Takes about 20 minutes.

Tester: ______________ Date: ______ Unity experience (years): ____ Version of Blockwerk: ______

## Tasks

The tester says out loud what they expect before they click. Mark: ✔ found it at once,
~ found it after looking, ✘ needed help or did not find it.

## Questions

1. Which Unity habit did **not** work here? (shortcut, window, word, behaviour)
2. Which word or window was named differently from what you expected?
3. Did the block scripts feel like "components on objects" the way scripts do in Unity?
4. Where did you feel lost? Where did you feel at home?
5. Would you build a small game with it? What is missing first?
